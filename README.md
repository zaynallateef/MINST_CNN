# MNIST (Modified National Institute of Standards and Technology) is one of the most popular datasets for learning Deep Learning, Computer Vision, and Image Classification.

## The goal is simple : train a neural network to recognize handwritten digits from 0 to 9.

## 70000 total images

## Each image has these properties :
- Grayscale: One channel instead of RGB's three channels.
- Resolution: 28 × 28 pixels, or 784 pixel values.
- Pixel intensities: From 0 (black) to 255 (white).
- Labels: Ten classes, representing digits 0 through 9.
- Preprocessing: Original MNIST images have already been size-normalized and centered.
